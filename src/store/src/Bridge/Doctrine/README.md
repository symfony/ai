Doctrine Store
==============

Stores vectors in a column of a Doctrine entity's own table and returns entities when queried, for
Symfony AI Store. Supports PostgreSQL with pgvector and SQLite with sqlite-vec.

See the [Doctrine store documentation](https://symfony.com/doc/current/ai/components/store/doctrine.html)
for the entity mapping, the column setup and indexing entities.

Doctrine Store Documentation
----------------------------

 * [Doctrine ORM custom mapping types](https://www.doctrine-project.org/projects/doctrine-orm/en/current/cookbook/custom-mapping-types.html)
 * [pgvector (operators, HNSW indexes, operator classes)](https://github.com/pgvector/pgvector)
 * [sqlite-vec (distance functions)](https://alexgarcia.xyz/sqlite-vec/api-reference.html)
