## Controlled fixtures

`controlled.pdf` and `untitled.pdf` are generated by `php generate.php` in this
directory and distributed under this package's MIT license. Both have text on
pages 1 and 3 and a blank page 2. The first includes a PDF title and XMP
metadata; the second has no document properties. No external generator is needed.
