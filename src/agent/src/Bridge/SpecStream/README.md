SpecStream AI Tool
==================

Provides [SpecStream](https://specstream.ai/) integration for Symfony AI Agent.

The bridge adds two tools: `specstream_search` runs the SpecStream Search API
and `specstream_extract` reads pages with the Extract API. Every result is
recorded as a source.
