Cheaper Inference Platform
==========================

Cheaper Inference platform bridge for Symfony AI.

Cheaper Inference is an OpenAI-compatible LLM gateway. The bridge uses its chat
completions endpoint through the Generic bridge, including streaming and tool calling.

See the [full documentation](https://symfony.com/doc/current/ai/components/platform/cheaperinference.html)
for setup and usage details.
