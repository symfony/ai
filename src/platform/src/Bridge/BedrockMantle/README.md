Bedrock Mantle Platform
=======================

AWS Bedrock Mantle platform bridge for Symfony AI.

The Mantle endpoint exposes OpenAI-compatible APIs (Chat Completions and Responses) for models
served through AWS Bedrock, so this bridge reuses the plain OpenAI wire protocol instead of the
AWS SDK used by the [Bedrock bridge](../Bedrock).
